\# Текстовый "Сейф"



!\[Python](https://img.shields.io/badge/Python-3.8+-blue.svg)

!\[License](https://img.shields.io/badge/License-MIT-green.svg)



Программа для безопасного хранения текстовых секретов с использованием шифрования заменой символов.



\## 📋 Возможности



\- 🔒 Шифрование текста заменой символов

\- 🔓 Дешифрование текста обратной заменой

\- 💾 Автоматическое сохранение в файл JSON

\- 📁 Загрузка данных при запуске

\- 🔍 Поиск по секретам

\- 📊 Статистика

\- 🗑️ Удаление секретов
